# The Terraform provider is a separate artifact target built on the generated Go SDK

Terraform provider generation (`crates/suspect-codegen/src/terraform.rs`) is not a thirteenth SDK language and sits outside the backend registry. The provider uses the Terraform Plugin Framework and depends on the unchanged generated Go SDK, pinned by version and `h1` checksum. Every API call, auth step, codec and validation goes through that SDK, so SDK fixes reach the provider through the dependency instead of a second HTTP implementation. Terraform lifecycle semantics (CRUD bindings, identity/import, computed/sensitive/write-only, missing-resource and partial-failure handling) come from a closed, versioned mapping file (`suspect.terraform.lifecycle.v1`) and are never inferred from operation names (ADR-0011). Retry and polling are `none` in v1.
