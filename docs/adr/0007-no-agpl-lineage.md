# Keep the codebase free of AGPL lineage

Speakeasy's `openapi-generation` and other AGPL-licensed generators may be studied for architecture and ideas. No source, template text or test fixture from them may be copied or mechanically translated into suspect. Ideas and interfaces are not copyrightable; code is, and copied code can only be removed by rewriting it. Patterns adopted this way (diagnostic fix guidance, the evidence-backed feature registry, the admission API, toolchain manifests) were reimplemented from scratch.
