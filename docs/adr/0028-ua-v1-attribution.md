# Every request carries a versioned `ua/v1` attribution User-Agent

Generated SDKs send `suspect/<generator-version> <identity>/<version> (<language>/<runtime-version>; openapi/<spec-version>)` on every request, including pagination pages, streams and OAuth token endpoints (`crates/suspect-codegen/src/attribution.rs`). The format is fixed and versioned so API owners can tell suspect-generated traffic, and raw SDK use from identified applications. A client-supplied application identifier replaces the SDK name/version slot rather than being appended, keeping those two populations separable. The `suspect/` token is always first and the header never contains environment-derived data. An explicit caller User-Agent wins, and each language has a way to suppress the header. A machine-readable companion header was considered and left out of v1. Changing the format requires a new template version.
