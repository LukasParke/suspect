# Environment credentials are opt-in, names-only and bound at client creation

Generated SDKs read credentials from the environment only when the generation config maps security scheme names to environment variable names (`credential_env: {version: "v1", schemes: {…}}`), or when `sdk_defaults.env_prefix` opts in to `<ENV_PREFIX>_API_KEY` (ADR-0011). No variable name is inferred from API titles, scheme names or extensions. Values are read once, when the client is created, never at generation, import or per-request time. An explicitly passed credential is authoritative as a whole and never filled in from the environment. Missing values fail before any HTTP request, and only for operations that need them. Without a policy the output is byte-identical. The reference for each language's API is `docs/SDK-CREDENTIAL-ENV.md`.
